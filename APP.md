# Как проверить запуск и закрыть «Линию»

«Линия» работает в фоне. После запуска найдите программу по имени в списке системных процессов. Рабочий стол остаётся свободным, а фотографии приходят в Telegram.

## Windows

**[Первый запуск на Windows с картинками](WINDOWS.md)**

1. Нажмите правой кнопкой на скачанный ZIP, выберите **«Извлечь всё»** и откройте полученную папку. Дважды нажмите **`Liniya.exe`**. Если Windows показывает предупреждение, закройте его. [Если на Windows что-то не работает](WINDOWS-HELP.md). Приложение запускается прямо из этой папки. Для следующего занятия откройте тот же файл.
2. **Проверка.** Нажмите **Ctrl + Shift + Esc**. В «Диспетчере задач» откройте **«Подробности»** (в некоторых версиях — **«Сведения»**). Если видите маленькое окно Windows 10, сначала нажмите **«Подробнее»**. Найдите **`Liniya.exe`** латиницей. На вкладке «Процессы» смотрите раздел **«Фоновые процессы»**. Именная сборка 3.1 отображается под именем ученика, например **Liniya — Илья**.
3. **Закрытие.** Выделите `Liniya.exe`, нажмите **«Снять задачу»** или **«Завершить процесс»** и подтвердите. Строка исчезнет, стрелка ↓ освободится.

В папке версии 3.1 можно также открыть **«Проверить работу.cmd»**. Он покажет, какая копия запущена. Если процесса нет, запустите `Liniya.exe` из распакованной папки.

## Mac

**[Установка на Mac с картинками — от скачивания до первого снимка](MAC.md)**

1. Распакуйте ZIP, перенесите **«Линия — ваше имя»** в «Программы» и откройте двойным щелчком. Для первой съёмки разрешите запись экрана в **Системные настройки → Конфиденциальность и безопасность**. Если macOS попросит перезапустить приложение, согласитесь.
2. **Проверка.** Через **⌘ + пробел** откройте **«Мониторинг системы»**. Выберите **Вид → Все процессы**, вкладку **«ЦП»** и в поле поиска введите **`Линия`**. Найдите своё имя, например **«Линия — Илья»** или **«Линия — Тест»**. Для прежней версии 3.0 попробуйте также **`Liniya`** латиницей.
3. **Закрытие.** Выделите нужный процесс, нажмите кнопку **ⓧ «Остановить»** на панели инструментов и выберите **«Завершить»**. Если процесс не отвечает, выберите «Завершить принудительно». Проверьте, что строка исчезла.

## Если «Линия — Тест» не открывается или снимок не приходит

**Finder показывает ошибку `−47` при повторном открытии из «Загрузок».** Откройте «Мониторинг системы» и найдите процесс **«Линия — Тест»**. Если он уже запущен, завершите его кнопкой **ⓧ** и дождитесь исчезновения строки. Затем откройте тестовую копию из «Программ». Если приложение пока лежит в «Загрузках», сначала перенесите его в «Программы».

**Приложение запущено, но при нажатии ↓ снимка нет.** В Finder нажмите **⇧⌘G** и введите `~/Library/Application Support/Liniya-test/status.txt`. Если в файле написано «Разрешите запись экрана», выполните следующие шаги.

1. Откройте **Системные настройки → Конфиденциальность и безопасность → Запись экрана и системного звука**. Включите запись экрана для **«Линия — Тест»**. Если приложения нет в списке, нажмите **+**, затем **⇧⌘G**. Введите `~/Applications/Линия — Тест.app` для личной папки «Программы» или `/Applications/Линия — Тест.app` для общей.
2. Согласитесь на перезапуск, если macOS его предложит. Иначе завершите «Линия — Тест» через «Мониторинг системы» и снова откройте из «Программ».
3. Снова откройте `status.txt` и проверьте время записи. Готовность обозначена сообщением «Компьютер подключён. Нажмите ↓ для отправки снимка в Telegram». В тестовом боте выберите свою роль, покажите пробное задание и один раз нажмите и отпустите **↓**. В чате должна появиться фотография с номером. ## Как проверить отправку

Откройте свой бот на телефоне, войдите в роль и покажите на компьютере пробное задание. Один раз нажмите и отпустите **↓**. Когда фотография появится в Telegram, проверка пройдена. Преподаватель может присылать ответы позже. Перед закрытием программы дождитесь появления последних снимков в чате.
