# Как преподавателю проверить «Линию»

Для проверки достаточно одного компьютера и одного Telegram-аккаунта на телефоне. Тестовое приложение 3.2.1 отправляет снимок через сервер «Линии» в один тестовый бот.

[Первый запуск на Mac](MAC.md) · [Первый запуск на Windows](WINDOWS.md)

1. **Скачайте [тестовое приложение для Windows](https://github.com/Uutotora/liniya-apps/releases/download/testing-v3.2.1/Liniya-test-Windows-win-x64.zip) или [для Mac](https://github.com/Uutotora/liniya-apps/releases/download/testing-v3.2.1/Liniya-test-macOS.zip)**. Распакуйте архив. На Windows откройте `Liniya.exe`. На Mac перенесите «Линия — Тест» в «Программы», откройте и разрешите запись экрана. Приложение работает в фоне. [Как проверить запуск и закрыть его](APP.md).
2. На телефоне откройте [тестовый бот «Линия»](https://t.me/liniya_class_20261012_bot). Нажмите **Старт → Я преподаватель** или напишите `учитель`. Отправьте пароль отдельным сообщением по запросу бота. Пароль передаёт организатор. После входа вам доступны обе роли.
3. Нажмите **☰** в строке меню Mac или возле часов Windows. Выберите **«Включить отправку по ↓ или ↑»**. Покажите пробное задание и через **☰ → Отправить пробный снимок** отправьте первый снимок. Прокрутите страницу колёсиком и нажмите **↑** для второго. Обе фотографии придут в чат до ответа преподавателя.
4. Выберите **«Ответить»** в меню первой фотографии в Telegram и напишите «Проверь вторую строку». В копии для ученика нажмите на цитату и проверьте, что Telegram вернул вас к нужному снимку.
5. Прямо в чат напишите, например, **«Второй снимок — ответ 7. Первый — ответ 4»**. Бот покажет в этом же чате копию для ученика. Нажмите **«Скопировать ответ»** и вставьте результат в поле ввода для проверки.

Чтобы проверить управление доступом, нажмите **Доступ приложений → Тест → Приостановить отправку**. Для продолжения выберите **«Возобновить отправку»** и сделайте новый снимок.

Завершив проверку, дождитесь последних фотографий в чате и [закройте «Линию» на компьютере](APP.md). Кнопка **«Выйти»** завершает роль в Telegram.

Чтобы проверить свою клавишу, нажмите **☰ → Приостановить отправку → Настроить клавишу…**, нажмите желаемое сочетание и снова включите отправку. Клавиши, занятые системой, выбрать нельзя.
