# Если «Линия» не работает на Windows

Найди строчку, похожую на то, что ты видишь на компьютере.

| Что видно | Что сделать |
| --- | --- |
| Нажимаю «Скачать», но файла нет | Нажми **Ctrl + J** в браузере. Там видно, завершилась ли загрузка. Если появилась ошибка, передай преподавателю её текст. |
| Windows пишет «Система Windows защитила ваш компьютер» или спрашивает про доступ к сети | Закрой сообщение и передай преподавателю его точный заголовок. Защиту Windows и настройки сети менять не нужно. |
| «Снимок ожидает сети» | Программа запустилась и сделала снимок. Она ещё не получила подтверждение приёма. Подожди немного. Если сообщение остаётся, скажи преподавателю, в какое время ты нажал ↓. |

**Если нужно отправить задание сейчас**, нажми **Win + Shift + S** и выдели только задание. В Telegram на компьютере открой чат со своим ботом, нажми **Ctrl + V**, проверь картинку и нажми **«Отправить»**.
